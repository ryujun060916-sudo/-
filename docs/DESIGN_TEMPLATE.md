# Visual Design System (DESIGN.md)

本ファイルは、AIエージェントがUIコード（HTML, CSS, React, など）を生成する際に参照するデザイン仕様書です。UIを構築する際は、必ずこのルールに従ってください。

## 1. トーン＆マナー
* **ブランドイメージ:** モダン、シンプル、親しみやすい
* **コアバリュー:** ユーザーフレンドリーでアクセシブルであること

## 2. カラーパレット (Colors)
指定された役割（トークン）に応じて、以下のカラーコードを厳密に使用してください。
* **Primary (ブランドカラー):** `#4F46E5` (例: インディゴブルー)
* **Secondary (アクセント):** `#10B981` (例: エメラルドグリーン)
* **Background (背景):** `#F9FAFB` (例: オフホワイト)
* **Text Main (本文テキスト):** `#111827` (例: チャコールブラック)
* **Text Muted (薄いテキスト):** `#6B7280` (例: グレー)
* **Border (境界線):** `#E5E7EB` (例: ライトグレー)

## 3. タイポグラフィ (Typography)
* **フォントファミリー (日本語):** `"Inter", "Noto Sans JP", "Hiragino Sans", sans-serif`
* **フォントファミリー (英数字):** `"Inter", system-ui, -apple-system, sans-serif`
* **ベースフォントサイズ:** `16px` (1rem)
* **見出し 1 (h1):** `2rem` (32px), `line-height: 1.2`, 太字
* **見出し 2 (h2):** `1.5rem` (24px), `line-height: 1.3`, 太字
* **本文 (p):** `1rem` (16px), `line-height: 1.5`

## 4. スペースとレイアウト (Spacing)
余白や配置は、以下の8pxグリッドシステム（ベースは4px）を基準に設定してください。
* `px` (Padding/Margin): `4px`
* `spacing-1` (最小の余白): `8px`
* `spacing-2` (標準的な余白): `16px`
* `spacing-3` (セクション間の余白): `32px`
* `spacing-4` (大きな余白): `64px`
* **レイアウト方式:** CSS Flexbox または CSS Grid を優先的に使用すること。

## 5. コンポーネントスタイル (Components)
* **ボタン (Button):**
  * 角丸 (border-radius): `8px`
  * パディング: 縦 `10px`, 横 `16px`
  * シャドウ: `none`
  * ホバー時のエフェクト: 背景色を少し暗くし、`transform: translateY(-1px)`を適用
* **カード (Card):**
  * 背景: `#FFFFFF`
  * 角丸 (border-radius): `12px`
  * 境界線: `1px solid [Border Color]`
  * 影 (box-shadow): `0 4px 6px -1px rgba(0, 0, 0, 0.1)`

## 6. レスポンシブ振る舞い (Responsive)
* **モバイルファースト**で設計すること。
* **ブレイクポイント:**
  * スマホ (Mobile): `~ 639px`
  * タブレット (Tablet): `640px ~ 1023px`
  * デスクトップ (Desktop): `1024px ~`

## 7. アクセシビリティ (Accessibility)
* すべてのテキスト（特に警告やエラーメッセージ）は、背景色とのコントラスト比を `4.5:1` 以上にすること。
* 画像には必ず `alt` 属性を記述すること。

## 8. エージェントプロンプトガイド (Agent Prompt)
AIエージェントへの指示です。コードを生成する際は、以下のルールを遵守してください。
1. 上記のトークン（変数名またはカラーコード）をハードコードせず、可能な限りCSS変数またはTailwindのクラスを用いて表現してください。
2. 日本語が不自然にならないよう、文字間隔（`letter-spacing`）や行間を適切に調整してください。
3. 未知のデザイン要素を生成する場合は、事前にユーザーに質問するか、このデザインシステムに準拠した形で提案してください。
